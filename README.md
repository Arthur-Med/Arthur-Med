## Experience & Featured Engineering Work

### Rede ATER Leite &mdash; National Monitoring & Analytics Platform
**Organization:** Embrapa Gado de Leite *(Internal Production System)*  
**Tech Stack:** Python, Django, PostgreSQL, Vanilla JS, CSS3, Chart.js, OpenPyXL, APScheduler

Designed and developed an enterprise web platform to monitor technology adoption and forage cultivar performance (BRS Capiaçu, BRS Kurumi, and BRS Integra) across dairy farms nationwide.

- **Data Aggregation Engine:** Built analytical modules consolidating heterogeneous field records into state and municipal indicators (Cross-Data Analysis, Daily Production Tiers, and Area Averages per Municipality).
- **Dynamic Multi-Select Filtering:** Engineered a state-preserving multi-cultivar filter system capable of recalculating KPIs, dynamic table columns, charts, and Excel exports on the fly.
- **Query & Backend Optimization:** Structured relational queries using Django ORM with eager loading (`select_related`) and custom sanitization pipelines to handle unstructured survey inputs without performance degradation.
- **Automated Executive Reporting:** Created a programmatic spreadsheet engine (`OpenPyXL`) that exports multi-tab, institutionally styled `.xlsx` reports synchronized with the user's active filter state.
- **Security & Reliability:** Implemented role-based permissions restricting destructive actions to superusers, alongside automated 12-hour background integrity checks via `APScheduler`.
